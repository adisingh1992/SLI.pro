# prompts/

Danielle's journalling prompts, for `npm run wing:tag-prompts`.

## Why this is not `methodology/`

`methodology/` holds her documents byte-for-byte, verified by hash, and every file in it
carries a baselined IG-RC13 claim count. These two files satisfy neither condition:

- **They are transcriptions, not the originals.** They were reconstructed from the project
  copies rather than committed from the files she sent. Structurally verified — 220 prompts,
  every id present exactly once, per-block counts matching the source — but not hash-identical.
  **Replace them with the originals when those are to hand.**
- **They are not linted.** The prompt copy almost certainly contains population claims:
  "At your level, nobody's testing your competence" is a stage norm by IG-RC13's own
  definition. Adding them to `methodology/` would move the corpus total in the same week we
  told her it was 195, so the number needs a decision behind it rather than a directory move.
  That is a question for the next email.

## The two files

**`wing-approachable-microjournal-library.md`** — the full library. 220 prompts present:
80 universal, 70 audience-adapted, 70 audience-specific.

Its own summary says 235, and its summary table implies 245. Against the contents there is no
Entrepreneur (Early)-Only block at all, and the two blocks headed "(10)" contain five each. So
25 prompts are named in her table and absent from the document. `wing:tag-prompts` prints that
comparison rather than hiding it.

**`wing-heartbeat-and-population-prompts.md`** — an extract of the prompt sections from
`Wing_All_Prompts_Copy_Final.md`: 48 heartbeat prompts across six tracks, plus the 28
new-population prompts from the UX Addendum. The module messaging, transitions, dashboard and
UX copy sections of that document are not here, because none of it is a journalling prompt.

Heartbeat prompts are numbered 1 to 8 within each track, so those ids repeat across tracks. The
report groups by block, which keeps them distinguishable.
