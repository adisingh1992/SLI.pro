Feature Request: Home Page Redesign – Dashboard Style Layout

Objective:
Completely redesign the current home page into a responsive, user-friendly dashboard layout that clearly guides the user through each stage of their professional branding journey.

Dashboard Layout & Section Structure:

Organize the page into responsive, visually distinct widget-style sections, using a 2-column layout on desktop and a single-column stacked layout on mobile.

Section Order and Behavior (from top to bottom):
Initial Questionnaire

Always the first visible section.

Retain all existing validation logic.

Documents Upload

Displayed only after the questionnaire is submitted.

Disappears once the required documents are uploaded.

Existing validations remain in place.

Your Professional Profile

Displayed only after the documents are uploaded.

Shows a summary of the user’s submitted information and current status.

Schedule Your Strategy Session

Retains all existing validations.

Show after documents upload and profile are complete.

Freshness Report

Displayed only after both the questionnaire and document uploads are complete.

Remains disabled until these prerequisites are fulfilled.

Single Lasting Impression (SLI)

Remains disabled until the user has SLIs available (whether selected or not).

Includes a button to navigate to the SLI page.

LinkedIn Optimization

This section remains disabled until:

A resume is uploaded.

A LinkedIn PDF is uploaded.

A selected or refined SLI exists.

A Freshness Report has been generated.

Includes a button to begin the optimization process.

Monthly Professional Brand Check-In

Always available after initial onboarding.

Design Guidelines:

Use responsive layout:

2-column grid for desktop/tablets.

1-column stacked layout for mobile devices.

Each section should be a card-like widget with clear headers, icons, and progress indicators (e.g., status badges or step indicators).

Disabled sections should appear visually dimmed/greyed out with tooltips or messages indicating prerequisites.

Ensure consistent styling, padding, spacing, and intuitive navigation between sections.
