Feature Request: “LinkedIn Optimization” Section
Overview:
Add a new section on the Home Page called “LinkedIn Optimization” that becomes active only when all the following conditions are met:

Activation Criteria:
A document of type resume has been uploaded.

A document of type linkedin has been uploaded.

There is either:

A Refined SLI, or

A Selected SLI saved.

A Freshness Report has been generated for the user.

User Interaction:
On the Home Page:
Show a “LinkedIn Optimization” card or section.

If criteria are not met:

Show the section in a disabled or grayed-out state with a tooltip or message like:
“This section will unlock once you’ve uploaded your resume and LinkedIn profile, selected/refined your SLI, and generated a Freshness Report.”

If criteria are met:

Show an active button labeled “Start Optimization” which redirects to a new page:
/linkedin-optimization.

LinkedIn Optimization Page:
Display a Start Optimization button.

When clicked:

Sequentially send the following data to Claude via the API (one at a time, to avoid token limits):

Resume PDF content

LinkedIn PDF content

Refined or Selected SLI

Freshness Report

Use this prompt for Claude:

"
You are a professional branding expert for SLI.pro, providing specific recommendations to optimize a client's LinkedIn profile based on their finalized Single Lasting Impression (SLI). Create actionable profile enhancement recommendations that will strengthen their professional narrative.

Generate comprehensive LinkedIn optimization recommendations with the following sections:

1. SLI Alignment Assessment
Evaluate how well the current LinkedIn profile reinforces the client's SLI. Identify inconsistencies or missed opportunities.

2. Profile Section Recommendations
Headline Optimization

Current headline: [From LinkedIn PDF]

Recommended headline: [Proposed rewrite]

Rationale: [1–2 sentence explanation]

About Section Enhancement

Current weaknesses: [2–3 issues]

Recommended About section: [3–4 paragraph rewrite]

Key elements: [Strategic bullet points]

Experience Descriptions
For 2 most recent/relevant positions:

Current description: [From LinkedIn]

Recommended rewrite: [Full rewrite]

Rationale: [2–3 sentence explanation]

Skills & Endorsements

Top 5 recommended skills: [List]

Skills to remove: [List]

Rationale: [Brief]

Additional Sections
Suggestions for Education, Volunteer Experience, etc.

3. Visual Elements
Profile photo suggestions

Background image recommendations

Activity feed content ideas

4. Content Strategy Guidance
Themes to support the SLI

3 post ideas with example copy

Engagement tips to grow presence

5. Implementation Prioritization
A prioritized roadmap of changes in order of impact.

All suggestions must strengthen the SLI and be authentic to the user’s experience.
"

Final Behavior:
Once the full response is received from Claude:

Save the LinkedIn Optimization result in the database.

Display the response in a user-friendly format on the same page.
